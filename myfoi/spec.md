# Portfolio Website Brief

## 5W1H Framework

### What
สร้างเว็บไซต์ Portfolio แบบ Single Page สำหรับนักเรียนชั้น ม.3 เพื่อใช้ยื่นประกอบการสัมภาษณ์เข้าศึกษาต่อชั้น ม.4 สายการเรียนวิทย์-คณิต

### Who
- ครูแนะแนว
- คณะกรรมการสอบสัมภาษณ์
- ผู้ชมผ่านมือถือหรือแท็บเล็ต โดยต้องการข้อมูลสั้น กระชับ และเจอเร็วภายใน 1-2 นาที

### Why
- นำเสนอผลงานในรูปแบบดิจิทัลที่ทันสมัย
- รองรับการแชร์ผ่าน QR Code หรือ Link
- เน้นความสามารถด้าน Digital Literacy
- ลดข้อจำกัดของการนำเสนอแบบกระดาษ

### Where / When
- ใช้แสดงผลระหว่างการสัมภาษณ์เข้าศึกษาต่อชั้น ม.4
- สามารถเปิดดูได้ทุกที่ทุกเวลาผ่านอุปกรณ์มือถือ

### How
- ใช้ HTML/CSS มีโครงสร้างหน้าเดียว (Single Page)
- เนื้อหาต้องสั้น ชัดเจน และอยู่ในรูปแบบ bullet point
- ไม่ใช้แอนิเมชันแบบวิบวับหรือหนักเกินไป

### Content Outline
- Hero: ชื่อ-นามสกุล, สายการเรียน, คำแนะนำตัวสั้น
- About & Education: ประวัติส่วนตัว, คติประจำใจ, เกรดเฉลี่ย
- Skills: ทักษะวิชาการ, Soft Skills, ความสามารถพิเศษ
- Awards & Projects: 3-4 ผลงานเด่นพร้อมคำอธิบายสั้น
- Activities: กิจกรรมและจิตอาสาที่เคยเข้าร่วม
- Contact: อีเมล, เบอร์โทรศัพท์, Line ID

### Visual Style
- โทนสีขาว-ฟ้า ดูวิชาการ สบายตา และเป็นระเบียบ
- Responsive Design สำหรับทุกขนาดหน้าจอ
- Layout ขนาดกะทัดรัด เหมาะกับการอ่านบนมือถือ
